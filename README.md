# SocialLune

Este é o SocialLune, uma rede social simples com login, feed, curtidas e comentários.

## Como publicar no GitHub Pages

1. Cria um repositório no GitHub chamado `SocialLune`.
2. Faz upload dos ficheiros:
   - login.html
   - home.html
3. Vai a **Settings → Pages**, seleciona:
   - Branch: main
   - Folder: / (root)
4. Clica em **Save**.
5. Em alguns minutos, o GitHub vai gerar o URL público do site, que terá o formato:

```
https://<teu-usuario>.github.io/SocialLune/login.html
```
